# OscarTV Stream Addon v0.2.0

Stream-only Stremio/Novio addon.

Render:
- Build: `npm install`
- Start: `npm start`
- Install URL: `https://YOUR-SERVICE.onrender.com/manifest.json`

Test:
`https://YOUR-SERVICE.onrender.com/stream/movie/tt0111161.json`

This version uses the concrete movie/series/watch-link endpoint names found in the supplied OscarTV APK and probes read-only parameter variants. It only returns URLs actually received from the API.
