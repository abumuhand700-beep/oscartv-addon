# OscarTV Stream Addon v0.3
Stream-only Stremio/Novio addon. Uses the OscarTV API endpoints extracted from OscarTV v1.1.5 and resolves IMDb IDs through Cinemeta.

Deploy as a Node Web Service. Start command: `npm start`.
Manifest: `/manifest.json`
Movie stream: `/stream/movie/tt1234567.json`
Series episode stream: `/stream/series/tt1234567:1:2.json`
